# Sistema de Campanhas - Atacadão Farias (API) 🚀

Este repositório contém a **API** de um sistema centralizador de informações de campanhas de vendas. O projeto surgiu da necessidade de otimizar a visualização de dados gerados pelo ERP WinThor, consolidando relatórios densos em uma interface única e intuitiva.

> ⚠️ **IMPORTANTE:** Este é um repositório de **TESTES** e estudos. Nenhuma informação sigilosa ou dados reais sensíveis da empresa estão contidos aqui. O objetivo deste projeto é validar a arquitetura e funcionalidades de forma controlada.

## 📋 Contexto do Projeto

Nas rotinas do dia a dia, o WinThor gera grandes volumes de dados. No entanto, para obter uma visão completa de uma campanha, muitas vezes é necessário navegar por múltiplas rotinas e relatórios. 

Este sistema visa:
* **Centralizar:** Reunir dados de diferentes fontes do ERP em um só lugar.
* **Simplificar:** Transformar relatórios densos em informações visuais e diretas.
* **Agilizar:** Facilitar a tomada de decisão para a equipe comercial do Farias.

## 🛠️ Tecnologias Utilizadas (Backend)

* **Java** 
* **Spring Boot** (Spring Data JPA, Spring Web)
* **MySQL Database** (Banco de Dados que escolhi para realizar meus testes)
* **Maven** (Gerenciador de dependências)

## 🏗️ Arquitetura

O projeto foi construído seguindo os princípios de uma API RESTful. 
* Este repositório foca exclusivamente na **lógica de negócio e acesso a dados**.
* O **Front-end** será desenvolvido em um repositório separado (em breve).
